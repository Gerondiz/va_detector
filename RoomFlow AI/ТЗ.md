# Техническое задание
## Учебный проект: система детекции и анализа аудио/видео с LLM

### 1. Цель

Разработать локальную систему для изучения функционала распознавания аудио и видео
с использованием нейросетевых моделей. Система работает с одной сетевой камерой (RTSP,
со встроенным микрофоном).

### 2. Задачи

- захват видеопотока с IP-камеры по RTSP;
- детекция и трекинг объектов в кадре (YOLO);
- распознавание речи с микрофона камеры (Whisper);
- анализ событий через локальную LLM (Ollama / LM Studio);
- логирование событий;
- визуализация результатов на экране.

### 3. Архитектура

```
IP Camera (RTSP, видео + аудио)
    │
    ├── Video → YOLO → ByteTrack → события (объект, время, зона)
    ├── Audio → Whisper → текст
    │
    └── LLM (Ollama/LM Studio)
         ├── Анализ: "В кадре человек, сказал 'помогите' — классифицировать"
         └── Ответ: {classification, reason, action}
              ↓
         Лог событий (JSON)
```

### 4. Стек

| Компонент | Инструмент |
|---|---|
| Захват видео | OpenCV (RTSP) |
| Детекция объектов | YOLOv8/v11 (Ultralytics) |
| Трекинг | ByteTrack (Ultralytics) |
| Распознавание речи | faster-whisper |
| VAD | Silero VAD |
| LLM (анализ событий) | Ollama / LM Studio (локально, REST API) |
| Логирование | JSON |

### 5. План реализации

**Шаг 1. Захват видео + YOLO детекция**
- подключение к RTSP камере через OpenCV;
- детекция объектов YOLO;
- отображение на экране.

**Шаг 2. Трекинг объектов**
- ByteTrack для отслеживания ID объектов;
- логирование появления/исчезновения.

**Шаг 3. Распознавание речи**
- захват аудио с микрофона камеры;
- Whisper (faster-whisper) для ASR;
- Silero VAD для детекции голосовой активности.

**Шаг 4. LLM для анализа событий**
- локальный LLM через Ollama или LM Studio (REST API);
- формирование промпта: описание кадра + распознанный текст;
- LLM классифицирует: угроза / норма / неопределённо;
- вывод результата на экран и в лог.

**Шаг 5. Логирование**
- JSON-лог с временными метками;
- сохранение скриншотов событий.

### 6. Формат взаимодействия с LLM

**Запрос (POST /v1/chat/completions)**

```json
{
  "model": "qwen2.5-7b",
  "messages": [
    {
      "role": "system",
      "content": "Ты — система анализа событий безопасности. Классифицируй ситуацию по описанию кадра и распознанной речи. Ответь строго в JSON: {\"classification\": \"safe|threat|uncertain\", \"reason\": \"...\", \"action\": \"...\"}"
    },
    {
      "role": "user",
      "content": "Кадр: человек в restricted zone. Речь: 'помогите'. Объекты: person (conf 0.92)."
    }
  ]
}
```

**Ответ LLM**

```json
{
  "classification": "threat",
  "reason": "Человек в запрещённой зоне + крик о помощи",
  "action": "Отправить алерт оператору"
}
```

### 7. Структура проекта

```

├── main.py              # Главный скрипт
```

### 8. Зависимости (requirements.txt)

```
opencv-python

torch

```

### 9. Запуск LLM

**Ollama**
```bash
ollama pull qwen2.5:7b
# или для русского: ollama pull llama3.2:3b
```

**LM Studio**
- скачать модель (например Qwen2.5-7B);
- запустить локальный сервер (по умолчанию http://localhost:1234/v1).
