Алгоритм самообучения зоны (Без ИИ и ручной разметки)Дверь — это место, где люди всегда появляются из ниоткуда (вход) и всегда исчезают (выход). Комната для YOLO — это замкнутая коробка, и только в одной определенной области кадра трекер ByteTrack постоянно фиксирует аномалию: резкое создание нового ID или резкую утерю старого.Система может разметить зону двери сама за 3 шага:Шаг 1. Сбор точек «материализации» (Статистика)В коде pipeline.py вы отключаете триггеры входа/выхода и запускаете систему в режиме «обучения» на пару дней.Как только ByteTrack выдает новый ID (первый кадр трека), скрипт записывает координату ног человека (x_center, y_bottom).Как только ByteTrack теряет ID (последний кадр перед исчезновением), скрипт снова записывает координату ног.Шаг 2. Фильтрация шума (Кластеризация)Люди могут садиться на диван, уходить за шкаф, и там трекер тоже будет терять ID. Это внутренний шум комнаты.Но если построить график всех точек появления/исчезновения, вы увидите, что в месте дверного проема образуется огромное, сверхплотное облако точек.Для автоматического поиска этого облака в Python используется простейший алгоритм машинного обучения без учителя — DBSCAN или K-Means (из библиотеки scikit-learn):pythonfrom sklearn.cluster import DBSCAN
# Алгоритм сам найдет самое густое скопление точек на экране и отбросит случайные шумы в комнате
dbscan = DBSCAN(eps=20, min_samples=10).fit(points_list)
Используйте код с осторожностью.Шаг 3. Автоматическое вычисление границ (Bounding Box зоны)Как только алгоритм нашел координаты этого густого облака точек дверного проема, скрипт берет его крайние значения:Самая левая точка облака автоматически становится вашим Door Zone — Left Edge (dx1).Самая правая — Right Edge (dx2).Самая верхняя точка, где ноги человека пересекали порог — вашей горизонтальной линией 0.91 (dy1).Система сохраняет эти вычисленные значения в базу данных settings, и при следующем перезапуске RoomFlow AI начинает работать по зоне, которую нарисовали сами люди своими шагами.
