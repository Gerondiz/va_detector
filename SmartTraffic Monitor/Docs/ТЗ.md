# Техническое задание: TrafficFlow AI

## 1. Назначение

Real-time система детекции, трекинга и подсчёта автотранспорта через камеру, направленную на проезжую часть. Фиксация направления движения и класса транспортного средства.

## 2. Стек технологий

- **Язык:** Python 3.10+
- **Детекция:** Ultralytics YOLOv8n (COCO: car, bus, truck, motorcycle)
- **Трекинг:** ByteTrack (built-in в Ultralytics)
- **Backend:** FastAPI
- **Шаблоны:** Jinja2
- **БД:** SQLite (события проездов, статистика)
- **UI:** Веб-интерфейс (дашборд + настройки + логи)
- **LLM (опционально):** LM Studio / Ollama для распознавания госномеров (v2)

## 3. Архитектура

```
IP Camera (MJPEG/RTSP)
  │
  ├── OpenCV → захват кадра
  ├── Detector (YOLOv8n) → детекция car/bus/truck/motorcycle
  ├── ByteTrack → стабильный трекинг
  ├── TrafficCounter → зона подсчёта + направление → publish
  ├── EventBus (Pub/Sub) — реиспользовать из RoomFlow AI
  │   ├── LoggerSubscriber → SQLite
  │   └── (опционально) AISubscriber → распознавание номера
  └── FastAPI + Jinja2 → веб-интерфейс
```

## 4. Компоненты

### 4.1 TrafficCounter (ядро системы)

Заменить `PeopleCounter` из RoomFlow AI на универсальный `TrafficCounter`.

**Логика подсчёта:**

```
Линия подсчёта: вертикальная или горизонтальная линия на кадре
Позиция: configurable (нормализованная координата 0–1)

Для каждого трека:
  - Отслеживаем предыдущий cx и текущий cx
  - Если трек ПЕРСЁК линию:
    - Если was_cx < line_x и now_cx >= line_x → ПРОЕХАЛ ВПРАВО
    - Если was_cx >= line_x и now_cx < line_x → ПРОЕХАЛ ВЛЕВО
    - Записать: класс ТС, направление, timestamp, скриншот
    - publish("passed", {class, direction, track_id, screenshot, crop})
```

**Дополнительно:**
- Cooldown по ID (10s) — не считать повторно одно ТС
- Подсчёт по классам отдельно
- Фильтр по confidence (по умолчанию 0.5)

### 4.2 Event Bus (реиспользование)

Взять `backend/event_bus.py` из RoomFlow AI без изменений:
- `passed` → параллельные потоки (логгер)
- (v2) `passed_ai` → AI-очередь для распознавания номера

### 4.3 База данных (SQLite)

**Таблицы:**

```sql
CREATE TABLE vehicle_classes (
    id   INTEGER PRIMARY KEY,
    name TEXT NOT NULL UNIQUE  -- car, bus, truck, motorcycle
);

CREATE TABLE events (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    vehicle_class   TEXT NOT NULL,
    direction       TEXT NOT NULL CHECK(direction IN ('left','right')),
    timestamp       TEXT NOT NULL DEFAULT (datetime('now')),
    screenshot      TEXT DEFAULT '',
    crop            TEXT DEFAULT '',
    confidence      REAL DEFAULT 0.0,
    track_id        INTEGER DEFAULT NULL
);

CREATE TABLE daily_stats (
    date        TEXT PRIMARY KEY,
    car_left    INTEGER DEFAULT 0,
    car_right   INTEGER DEFAULT 0,
    bus_left    INTEGER DEFAULT 0,
    bus_right   INTEGER DEFAULT 0,
    truck_left  INTEGER DEFAULT 0,
    truck_right INTEGER DEFAULT 0,
    moto_left   INTEGER DEFAULT 0,
    moto_right  INTEGER DEFAULT 0
);

CREATE TABLE settings (
    key   TEXT PRIMARY KEY,
    value TEXT NOT NULL
);
```

**Триггер:** при вставке в `events` автоматически обновлять `daily_stats`.

### 4.4 LoggerSubscriber

```python
"passed" → INSERT INTO events
         → обновить daily_stats
         → state.{class}_{direction} += 1
```

### 4.5 SharedState

```python
@dataclass
class TrafficState:
    frame: np.ndarray | None = None
    running: bool = True
    line_position: float = 0.5       # нормализованная позиция линии (0–1)
    line_horizontal: bool = False    # True = горизонтальная, False = вертикальная
    fps: int = 0
    # Счётчики по направлениям и классам
    car_left: int = 0
    car_right: int = 0
    bus_left: int = 0
    bus_right: int = 0
    truck_left: int = 0
    truck_right: int = 0
    moto_left: int = 0
    moto_right: int = 0
    _lock: threading.Lock = field(default_factory=threading.Lock)
```

## 5. Веб-интерфейс (Jinja2)

### 5.1 Дашборд (`/`)

- MJPEG-стрим с наложенной линией подсчёта
- Счётчики по направлениям (Left / Right)
- Счётчики по классам (car / bus / truck / motorcycle)
- Таблица последних проездов (время, класс, направление, скриншот)
- График (часовой трафик) — v2

### 5.2 Настройки (`/settings`)

- Позиция линии подсчёта (слайдер 0–1)
- Переключатель вертикальная/горизонтальная линия
- COCO-классы для отслеживания (чекбоксы car/bus/truck/motorcycle)
- Порог confidence (слайдер 0.3–0.9)
- Кнопка сброса счётчиков
- Статус LLM сервера (v2)

### 5.3 Логи (`/logs`)

- Скриншоты проездов с фильтром по дате и классу
- Пагинация
